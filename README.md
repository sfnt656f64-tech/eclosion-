# Éclosion

Mon application personnelle de progression, inspirée des RPG.
Chaque objectif de vie devient une créature qui éclot d'un œuf et évolue quand je progresse.

## Installer l'app

Ouvrir le site sur le téléphone, puis :
- **iPhone (Safari)** : bouton Partager › « Sur l'écran d'accueil »
- **Android (Chrome)** : bouton « Installer l'app », ou menu ⋮ › « Ajouter à l'écran d'accueil »

L'app fonctionne ensuite sans internet. Les données restent sur l'appareil :
pense à faire « Exporter mes données » dans Réglages de temps en temps.
